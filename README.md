# 인도네시아(KISI) 일일보고 자동화

한국투자증권 인도네시아 법인(KISI)의 일일 실적을 본사 보고용 표로 만들어 주는 **단일 HTML 도구**입니다.
설치·인터넷 연결이 필요 없고, 파일 하나를 브라우저로 열어 사용합니다.

## 구성

| 파일 | 설명 |
|---|---|
| `인도네시아_일일보고_자동화.html` | 도구 본체 (SheetJS 인라인, 오프라인 구동, 단일 파일) |
| `인도네시아_일일보고_사용설명서.docx` | 사용설명서 |
| `변경내역.md` | 개발·검증·수정 내역 |

## 사용 요약

1. 현지 엑셀(`rev_Daily_report_KISI_*.xlsx`)과 어제 저장한 원장(JSON)들을 화면에 끌어다 놓습니다.
2. 보고일을 넣으면 세부 일일보고 표(금일·주간·월간·분기·기)와 보고 양식이 만들어집니다.
3. 보고 양식을 그림(PNG)·엑셀·복사로 내보내 이메일에 넣습니다.
4. `오늘 작업 저장`으로 원장 6종(JSON)을 내려받아 보관하고, 다음 날 다시 올려 이어 씁니다.

## 저장 파일 6종

`ledger`(일자별 원자료) · `fx_ledger`(환율) · `holidays`(휴일) · `est_ledger`(주간 추정) ·
`close_ledger`(관리회계 확정 실적) · `form_config`(입력값). 브라우저에는 아무것도 저장하지 않으며 상태는 전부 JSON 파일로 오갑니다.

## 주요 기능

- 원천을 라벨(한글명·영문명·계정코드)로 찾아 일자별로 누적, 과거 값 변경을 자동 감지.
- 환율은 회계연도 기누적 평균(IDR/KRW)을 주차 고정으로 적용.
- **관리회계 확정 실적**: 마감월은 확정치로 고정하고 당월은 일데이터를 누적해 분기·기누적에 반영(추정→확정 2단계).

## 검증

작업파일 6개·로데이터 2개·주간추정 1개로 실측 검증, Playwright/Chromium 브라우저 기능검사까지 통과했습니다.
자세한 내용은 `변경내역.md` 참조.
